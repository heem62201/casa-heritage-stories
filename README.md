# Casa Guipuzcoana Story

Build a premium, ultra-luxury boutique hotel website for:

CASA GUIPUZCOANA

Hotel Boutique

Puerto Cabello, Venezuela

PROJECT TYPE:

High-end luxury hospitality website redesign/concept.

The website should feel like a $10,000+ custom-designed hospitality experience, not a generic hotel template.

PRIMARY GOAL:

Create a visually exceptional, editorial, emotionally immersive hotel website that makes the property feel exclusive, historic, intimate and luxurious, while making it extremely easy for guests to discover the hotel and book a stay.

IMPORTANT:

Use the uploaded hotel photography and uploaded video assets as the primary visual content throughout the website.

Do NOT replace them with generic stock photography unless an asset is genuinely missing.

Do NOT invent fake hotel photography.

Do NOT use random AI-generated hotel imagery when the provided assets can be used.

Preserve the authenticity of the property.

BRAND POSITIONING:

Casa Guipuzcoana is positioned as a historic luxury boutique hotel where colonial heritage meets modern elegance.

Visible brand/message direction from the supplied reference:

“History Lives Here”

“A 5-star boutique hotel where colonial heritage meets modern elegance.”

“More Than a Stay, A Story”

“Elegance is when history meets hospitality.”

The hotel is presented as:

• 5-star boutique hotel

• Historic colonial building

• Restaurant at 1730

• Exclusive beach club

• Personalized service

Do not make unsupported claims beyond the supplied content.

--------------------------------------------------

IMAGE / VIDEO ASSET RULES

--------------------------------------------------

Use the uploaded assets intentionally.

Prioritize:

1. Exterior night architecture image for hero

2. Historic courtyard image for story section

3. Interior architectural photography for hotel sections

4. Uploaded videos for cinematic storytelling

5. Additional supplied hotel images for rooms/gallery/experiences

Do not repeat the exact same image excessively.

Use image cropping that preserves architectural details.

For hero images:

Use cinematic crop and strong focal-point positioning.

For editorial sections:

Use different aspect ratios and compositions to create visual rhythm.

Videos:

• autoplay only when muted

• loop where appropriate

• pause when off-screen if practical

• provide poster image

• provide visible controls for interactive videos

• never autoplay audio
